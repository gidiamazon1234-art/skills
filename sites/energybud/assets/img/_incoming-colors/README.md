# Drop colour photos here

Upload the per-colour bottle photos into this folder — raw, any filename, any size.
I'll crop, resize, rename and wire them into the colour picker.

## What's needed

One photo per colourway per size. Ideal shot:

- **one bottle only**, that colour, whole bottle in frame
- plain / studio background (white is perfect)
- same framing and angle across all of them, so the picker doesn't jump when you switch
- portrait orientation, as large as you have

## Colours

lime · blue · pink · violet · turquoise · graphite (the grey/charcoal one — only if it's sold)

## Sizes

128 oz (1 gallon) and 74 oz (half gallon).

You don't need all twelve. Whatever lands here gets wired up; the rest stay hidden
until they arrive. If a colour only exists in one size, send that one.

Name them however you like — even `IMG_4821.jpg` — but if the colour isn't obvious
from the photo, put it in the filename.
