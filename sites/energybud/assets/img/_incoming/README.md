# Drop ALL your photos here

This is a **staging folder**. Upload the whole photo library here — any filenames, any sizes,
any formats (JPG / PNG / WebP). Nothing here is used by the site directly.

Claude will then:

1. Review every image and pick the best shot for each slot (hero, product gallery,
   colourways, lifestyle).
2. Crop / resize / compress each chosen one for the web and save it under
   `assets/img/` with the correct filename.
3. Delete this `_incoming/` folder in the same commit, so the repo stays clean.

**Don't worry about naming, size or file weight** — originals straight from the brand kit are
exactly what's wanted here. Bigger is better; downscaling happens automatically.
