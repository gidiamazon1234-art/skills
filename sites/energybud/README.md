# EnergyBud — Brand Site

A multi-page marketing + storefront site for **EnergyBud**, the 1-gallon (128 oz) motivational
water bottle. Built with the design system generated by the
[`ui-ux-pro-max`](../../.claude/skills/ui-ux-pro-max) skill.

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Home / landing — hero, features, hydration **Timeline**, colourways at both sizes, reviews, CTA |
| `product.html` | 1 gallon (128 oz) product detail — gallery, specs, accordion |
| `half-gallon.html` | Half gallon (74 oz) product detail — gallery, size comparison, colourways, its own six feature cards |
| `features.html` | Six feature cards from the brand's A+ photography, plus a comparison table |
| `about.html` | Brand story, values, stats |

Every buy CTA deep-links to the Amazon listing (`amazon.com/dp/B085LL6253`) in a new tab —
there is no on-site checkout, because the product is sold and fulfilled through Amazon.


## Shared assets

- `assets/styles.css` — the full design system (tokens, components, light/dark themes)
- `assets/fonts.css` — Barlow + Barlow Condensed inlined as base64 `@font-face` (no external requests)
- `assets/app.js` — theme toggle, scroll reveal, product gallery, photo fallbacks (50 lines, no dependencies)

## Design system (from the `ui-ux-pro-max` skill)

- **Style:** Vibrant & Block-based — bold, high-contrast, large sections
- **Palette:** water blue `#0284C7` + cyan `#06B6D4` + teal accent `#0891B2`, with the real brand charcoal `#333333` from the EnergyBud logo kit as the ink/inverted band
- **Type:** Barlow Condensed (display, athletic) + Barlow (body)
- **Motion:** staggered scroll reveals, animated hero water-fill, 150–300ms hover transitions
- **A11y:** WCAG-AA contrast, visible focus, `prefers-reduced-motion`, responsive at 375 / 768 / 1024 / 1440

## Run locally

It's static — open `index.html` directly, or serve the folder:

```bash
cd sites/energybud
python3 -m http.server 8000
# visit http://localhost:8000
```

## Colourways

The home page names the colourways — Lime Fade, Blue & Black, Pink Fade, Violet Fade and
Turquoise — as inline SVG swatches whose gradient stops were **sampled from the actual product
photography** (`A+_01` / `A+_02`), so the colours on screen match the bottles rather than being
approximated by eye.

Underneath, the same section shows the **line-up photographed at each size** — the gallon and the
half gallon, on the same track, each labelled and linked to its own page. That is the honest
answer to "which colours come in which size": both photos are of the real range.

One thing to settle before adding a count back to the copy: the half-gallon line-up photography
shows **six** distinct bodies (a graphite/charcoal fade sits alongside the five named ones), so the
headings deliberately say "every colourway" rather than a number.

## Sizes

Each size has its own page, cross-linked from a size chip on both. Reading both bottles' own
photography settled what actually differs between them:

- **Identical:** all seven motivational markers, word for word and hour for hour — 8 AM
  *Rise & Grind!* through 8 PM *Nearly There!*
- **Different:** the measurement scale, necessarily — 128 oz / 3780 ml on the gallon,
  74 oz / 2200 ml on the half gallon

The copy says exactly that rather than the vaguer "same time markers".

## Outbound tracking

Every Amazon CTA carries a `data-track` label (`hero`, `nav`, `pdp-buy`, `colorways`, …) and
`app.js` appends it as `ascsubtag` on click, so Amazon reports which button drove each visit.

To attribute sales — and qualify for the Brand Referral Bonus — fill in the two fields at the top
of the tracking block in `assets/app.js`:

```js
var AMAZON = { tag: 'your-associates-tag', attribution: 'your-attribution-id' };
```

Leaving them empty changes nothing; links keep working exactly as they are, including with
JavaScript disabled. The click handler also emits an event to Google Analytics (`gtag`),
Plausible or GTM's `dataLayer` if any of them is loaded, and does nothing when none is.

## Deployment

The site is static — no build step. It is hosted on **Bluehost** at
**https://energybuddd.com**, uploaded to `public_html/` via cPanel File Manager.

Full step-by-step, including migrating off the previous CloudBe host without downtime, is in
**[DEPLOY.md](DEPLOY.md)**. Read the first two steps before changing anything — where the domain
is registered, and whether any email runs on it, both decide the safe order of operations.

### What `.htaccess` does

- Forces HTTPS, and redirects `www.energybuddd.com` to `energybuddd.com` so there is one
  canonical host (matching the `canonical` tags)
- Serves `404.html` for missing pages
- Gzip compression, plus long cache lifetimes on images/CSS/JS and no-cache on HTML
- Lets `/product` work as well as `/product.html`

Upload it with hidden files visible in File Manager, or it will be silently skipped.

## SEO

Each page carries canonical, Open Graph and Twitter card tags; `product.html` and
`half-gallon.html` also ship Product structured data (schema.org) including the 4.4 / 1,146 rating and the $29.99 offer, so
search results can show rich product info. `robots.txt` and `sitemap.xml` are in this folder, both pointing at `https://energybuddd.com`.

After the site is live, submit `https://energybuddd.com/sitemap.xml` in Google Search Console.
